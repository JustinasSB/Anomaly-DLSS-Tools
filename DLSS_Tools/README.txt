DLSS_Tools v0.91.7 — Mod Organizer 2 package

Install this ZIP with MO2 and enable the DLSS_Tools mod.
In MO2 > Modify Executables, choose tools\Anomaly (DX11-NGX).exe
from the installed DLSS_Tools mod folder. Leave Arguments and Start In blank.
If the game cannot be detected, pass the absolute path to AnomalyDX11AVX.exe
as the launcher's first argument or set ANOMALY_NGX_GAME_EXE.

This mod requires a supported, hash-verified Anomaly/GAMMA executable,
DirectX 11, a compatible NVIDIA RTX GPU and NVIDIA drivers.
The mod is unofficial; NVIDIA DLSS and MinHook are third-party dependencies.
Build instructions and source: see the repository README.md.
